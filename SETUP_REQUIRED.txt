MANUAL STEPS TO FINISH THIS RELEASE (v1.13)
==============================================

1. INTAKE WEBHOOK -- if not already done, see the previous release's
   instructions (unchanged, already working if you've done this).

2. RESEND (for tech-assignment emails AND the new "Email to client"
   feature -- both use the same setup)
   ------------------------------------------------------------------
   a. Sign up free at resend.com
   b. Add and verify emaildone4u.com as a sending domain
   c. Create an API key
   d. Supabase project -> Edge Functions -> Manage secrets, add:
      RESEND_API_KEY = <the key from step c>
   Once set, BOTH the tech-assignment email and the "Email to client"
   button start working -- no separate setup needed for each.

3. STRIPE (new, for the invoice feature)
   ---------------------------------------
   a. Sign up at stripe.com if you don't already have an account
   b. Go to Developers -> API keys -> copy your Secret key
      (starts with sk_live_... for real charges, or sk_test_... to
      test without real money first -- recommended to test first)
   c. Supabase project -> Edge Functions -> Manage secrets, add:
      STRIPE_SECRET_KEY = <the key from step b>
   d. That's it -- "Create & send invoice" on any order will create a
      real Stripe invoice for that order's tier price and have
      Stripe email it to the client with a Pay button, no further
      setup needed.

   Note: invoice amounts are currently fixed to the standard tier
   prices ($150/$200/$300). If you add the separate-mailbox add-on
   fee or change pricing, tell Claude and this gets updated to match.

Until each of these is set up, the related features fail gracefully --
nothing else in the portal is affected, and the buttons just report
"not configured yet" instead of breaking anything.
